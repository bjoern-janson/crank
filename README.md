# CRANK

A causally separated experimental framework for studying context-sensitive
model behavior, corrective state, authority-preserving admissibility,
downstream behavior, environmental consequence, and temporal experience.

## Layer-0 phenomenon assay

The frozen primitive is:

```text
(X, C, e, B) -> raw implementation I -> exogenous evaluator A(I,E)
```

`raw_model_output` is the primary custody object. Parsing and evaluation happen
after capture. The probe does not claim a mechanism or learning effect.

The routing task contains two distinct valid alternatives after the preregistered
`A -> B` edge removal. The four cells are:

```text
             e0             e1
C0        baseline       perturbation
C1        baseline       perturbation
```

The primary empirical object is the implementation distribution:

```math
pi_hat(I | C,e,B)
```

A successful probe result is a behavioral distributional observation, not a
claim of frame, learning, representation change, or capability expansion.

## Full causal stack

```text
Phenomenon probe
    -> raw I
    -> exogenous evaluation
    -> evidence / warrant
    -> Corrective Buffer
    -> canonical S_B
    -> Authority-Preserving Adapter
    -> admissible space A
    -> downstream mechanism
    -> behavior
    -> environment / outcome
    -> experience
    -> explicit temporal state
```

The anti-credit-leakage rule is:

```math
No component receives credit for a causal transition it does not itself
implement and experimentally identify.
```

## Current frozen boundary

The existing temporal-revisability artifacts are retained unchanged. Layer 0
is added as an observational front end and receipt bridge. The saved buffer
snapshot in this repository predates direct empirical-claim insertion, so the
bridge intentionally emits a buffer-compatible authorized receipt without
modifying that frozen buffer API.
